Features
What the system does

Three core ML capabilities — not rule-based logic. Every prediction is data-driven.

🤖

AI prediction

Random Forest classifier trained on academic aptitude scores across 5 subject domains.

📊

Probability breakdown

Shows match percentage for all career paths — not just the top result.

📄

PDF report

Generates a printable career guidance report for each student with full analytics.

📈

Analytics dashboard

Seaborn visualisations showing class-wide trends and feature correlations.

🌐

Web interface

Deployed on Streamlit Cloud — no installation needed, runs in any browser.

🏫

Kazakhstan context

Career domains mapped to the Kazakhstani school curriculum and subject areas.

Methodology
How it works
01 · INPUT

Academic profile

Student scores (1–100) across 5 areas: technical, natural sciences, social, humanities, creative arts.

02 · MODEL

Random Forest

200-tree ensemble classifier trained with scikit-learn. Feature importance extracted and visualised.

03 · OUTPUT

Career path + report

Primary recommendation + probability ranking for all 5 domains + downloadable PDF report.
